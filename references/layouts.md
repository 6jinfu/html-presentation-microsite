# 版式

色板、字号和密度的数值在 `assets/tokens.json`。布局在 `assets/deck.css`。渲染器只填内容，不改这些文件。

## 主题和密度

- `boardroom`：浅色会议室投影，适合正式业务汇报。示例用这个主题。
- `showcase`：深色概念页，沿用本技能原来的展示气质。
- `calm` / `standard` / `compact`：只改变页边距、标题字号和间距。

中文标题用衬线栈，正文用黑体栈，都是系统字体，不下载字体，也不打包商业字体。每一行标题必须写成 `title_lines` 里的独立字符串，渲染成单独的 `.title-line`。

## 页面

| layout | 用途 | 内容 |
| --- | --- | --- |
| `cover` | 封面 | 判断句标题、一句说明、决策条 |
| `agenda` | 议程 | 3-5 条 |
| `chapter` | 章节重置 | 大号章节号和一句本章任务 |
| `thesis` | 判断 | 2-3 个支撑点 |
| `metrics` | 数字 | 3-4 个指标 |
| `comparison` | 取舍 | 左右两个方案 |
| `cards` | 结构 | 3-4 张卡片 |
| `roadmap` | 路径 | 3-4 个阶段 |
| `summary` | 收束 | 3-4 条 |
| `close` | 决定 | 一个请求和两个选项 |

10-15 页汇报保留章节页，用来重置节奏。这是本技能自己的结构，不是把每一页都做成封面。

## 画布

屏幕和打印共用 1920×1080 的画布。浏览器里按窗口缩放。打印为 13.333in × 7.5in，也就是 16:9。卡片使用 `min-width: 0` 和 `overflow: hidden`。键盘左右、Home、End、滚轮和底部圆点都能翻页。动画在 `prefers-reduced-motion` 下关闭。

## 检查器实际卡住的问题

- 标题、卡片和页脚超出画布或撑破自身盒子
- 两块文字重叠
- 内容页几乎没有文字，或证据区高度过低
- 中文样本「汇报」没有画出墨迹
- HTML 引用外部地址，或留下 `{{`、`TODO`、`Lorem`
- `formats` 里写了 `pptx`
